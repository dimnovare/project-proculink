# Troubleshooting

What to do when a document cannot be read, a send fails, or a result looks wrong.

Open the document first. Its screen says what went wrong and offers the next step when there is one.

## Couldn't read

The message tells you why.

- "This file couldn't be opened. It may be password-protected or damaged." Remove the password or ask the sender for a fresh copy, then upload it again. **Try again** is not offered, because the same file would fail again.
- "This workspace has used this month's AI allowance." Select **Try again** when your allowance starts again. See [How ProcuLink uses AI](/help/ai-in-proculink).
- "This looks like a scanned document, which can't be read yet." Scans and photos are not switched on for your workspace. Ask for a file with text in it.
- "This workspace keeps documents on our own servers, so they aren't sent to AI to be read." Contact support if that is not what you want.
- "We couldn't read this document." Select **Try again**. If it fails again, send the file to support.

See [Files we read](/help/what-we-read) for types and limits.

## Stuck on Received or Reading

Reading takes seconds, or a few minutes for a long file. If a document is still on **Received** or **Reading** after 15 minutes, contact [support](/support) and say which file it is.

## Needs review

A **Needs review** document is flagged on purpose. Read the flags beside the values. See [Checks](/help/checks). Some documents wait for another reason:

- "This file was already uploaded to this flow." Select **Read it anyway** if you want it read.
- "No output is set to send this document. Check “Send when” on the flow's outputs." Every output has a **Send when** condition, and none matched.
- "An output couldn't be made from this document. Check the flow's outputs." Open the flow's **Outputs** tab and check each one.

## Couldn't send

At least one output could not be delivered. Under **Deliveries**, each output has its own state. **Will retry** means we are trying again on our own. **Couldn't deliver** means we gave up, and the reason is printed under it. Fix the cause, then select **Send** again. Outputs already delivered are not sent twice. See [Destinations](/help/destinations).

If **Send** is refused, the message says why: "Add an output to this flow before sending.", "Confirm this flow's fields first." or "Processing is paused on this workspace." See [Plans and billing](/help/billing-faq).

## A value looks wrong

Type the right value. To have us find it next time, point at it on the page instead. See [Teach a value by pointing at the page](/help/guides/teach-a-value). A value marked **Not found on the page** is one we could not locate. Check it against the original.

## A document does not arrive

- If an upload is refused, the message says why: "This file type can't be read in this flow." or "This file is too large." The limit is 10 MB.
- After the trial: "Your trial has ended, so new documents aren't being accepted." Choose a plan in **Settings**.
- For email, a mailbox, a server or a bucket, open the flow's **Intake** tab and select **Test connection**. Each pickup shows when it last ran. See [Ways to send documents in](/help/intake-channels).
- For the API, the answer names the problem. See the [API reference](/help/api-reference).

## Only an admin can change this

Some settings are for workspace admins: "Only a workspace admin can change this." See [Workspace, team and API keys](/help/workspace-and-team).
