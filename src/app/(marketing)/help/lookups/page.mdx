# Lookups

How a lookup list turns one value into another, such as your item code into a supplier's.

A lookup is a table with two columns: **From** and **To**. When a file uses a lookup for a value, the value on the document is looked up in the **From** column, and the matching **To** is written instead. Use it for item codes, unit names, country names or anything else your receiving system spells differently.

Lookups are shared across your workspace. Find them from **Flows**: the link **Lookups** is under the list of flows. Any file in any flow can use any lookup. A lookup that no file uses yet says how to use it, with a link to each of your flows: open a flow, go to **We send**, open a file, choose **More options: when to send, separator, lookups** and pick the lookup for a column.

## How a match works

- We ignore spaces at the start and end of the value.
- We ignore capital letters. `ab-100` finds `AB-100`.
- The whole value must match. We do not match part of a value.
- Each **From** can appear once in a lookup.

## When a value is not in the lookup

Each swap says what to do with a value it cannot find:

- **Keep the value.** The original value goes into the file.
- **Leave it blank.**

Either way the file is still made. When you preview a file, the values that were not found are listed under it, so you can add them.

## Fill a lookup

- Select **Import a table** on **Lookups** and choose a CSV or Excel (.xlsx) file. Column 1 is **From**, column 2 is **To**, and the first row is read as headings. It is saved at once as a new lookup named after the file, and **Undo** takes it back. See [Import a lookup](/help/guides/import-a-lookup).
- Add or change rows by hand on the lookup's page. They save as you type.
- **Replace from a file** swaps all of a lookup's rows for the file's. **Undo** puts the old rows back.
- Press **Export CSV** to take the rows back out.

A lookup holds up to 20,000 rows. A value can be up to 200 characters.

## Let AI suggest matches

When you preview a file and a value was not found, a **Suggest matches** button can appear. It does when your lookup also has a list of values to choose from, for example your supplier's product list.

For each value that was missed, the suggestion shows what we propose, how sure we are when we can say, and the note from your list. You then choose:

- **Accept** adds the pair to the lookup.
- **Edit** lets you change the **To** value before it is added.
- **Reject** drops the suggestion and adds nothing.

Nothing is added until you press **Accept** or save an edit. Suggestions are never applied by themselves.

To make a suggestion, we send the missed value, the other values on the same row of the document (up to 500 characters), and values from your list: the whole list when it has 40 values or fewer, otherwise the 8 closest to each missed value. We do this for up to 25 missed values at a time. It counts against your workspace's monthly AI allowance, and it does not work if your workspace keeps documents on our own servers. See [AI in ProcuLink](/help/ai-in-proculink).
