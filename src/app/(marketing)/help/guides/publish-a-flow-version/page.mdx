import { guideMetadata } from "@/lib/seo";

export const metadata = guideMetadata({
  slug: "publish-a-flow-version",
  title: "Use changes and restore earlier versions — ProcuLink guide",
  description: "Need to change a flow safely? Make your changes, put them in use, undo the ones you do not want, and restore an earlier version if you need to.",
});

import { Step, Prereqs, IfThisFails, Outcome } from "@/components/help/guide";

<Prereqs>
- A workspace admin account. Putting changes in use and restoring are for admins.
- A flow you want to change. See [Flows](/help/flows) for what a version holds.
</Prereqs>

<Step n={1} title="Change the flow">

Change the values on the **We read** step, or add and edit files on the **We send** step. Changes save as you make them. Once the setup is saved, they wait until you use them; before that, they are in use straight away. Documents that are already running keep following the setup in use, so your changes do not disturb them.

A bar under the step tells you where you stand:

- Before the first save of the setup: "You're still setting up, so changes apply right away. Save this setup when it works."
- After: "Your changes aren't in use yet. New documents still follow the last saved setup."

<Outcome>
The bar offers **Save this setup** before the first save. After that it offers **Use these changes** and **Undo my changes**.
</Outcome>

</Step>

<Step n={2} title="Use your changes">

Select **Use these changes**. Any change still waiting is saved first. The bar then says your changes are in use. New documents are read with them, and documents still waiting for review are checked again against them.

<Outcome>
A new version appears at the top of **History of changes**, marked **In use**.
</Outcome>

<IfThisFails>
- **A change couldn't be saved.** Nothing is put in use. The bar names the step with the change, with a link to it.
- **There are no changes to use.** The flow already matches the setup in use.
- **Someone else put changes in use just now.** Reload to see the latest setup, then make your change again if it is gone.
</IfThisFails>

</Step>

<Step n={3} title="Undo changes you do not want">

Select **Undo my changes** and confirm. The flow goes back to the setup in use. This cannot be undone.

<Outcome>
The bar says your changes are undone.
</Outcome>

</Step>

<Step n={4} title="Restore an earlier version">

Open the flow's **History of changes**. Each version shows when it was put in use and by whom. Select **Restore** beside the one you want, and confirm.

Restoring does not put it in use. It replaces your changes with that version. Check the flow, then select **Use these changes** to put it in use as a new version.

<Outcome>
A message says the version is back in your changes and tells you to press **Use these changes** to put it in use.
</Outcome>

<IfThisFails>
A version cannot be restored if it sends to a destination, or uses a lookup, that has since been deleted. Change the flow by hand instead.
</IfThisFails>

</Step>

<Step n={5} title="See which version a document used">

Open any document. It says which version it was processed with.

<Outcome>
You can tell which setup produced a document.
</Outcome>

</Step>
