<Step n={1} title="Connect by signing in (Claude and ChatGPT)">

**Claude:** open "Customize", then "Connectors", select "Add", then "Add custom connector". Name it ProcuLink and paste `https://api.proculink.eu/mcp`. Select "Connect", sign in to ProcuLink and choose your workspace.

**ChatGPT:** open "Plugins", select "+", then "Add custom MCP server". Paste the same address and choose "OAuth". Open "Advanced OAuth settings", set "Registration method" to "Client Identifier Metadata Document (CIMD)" and untick the box under "OpenID support". Create it, then sign in to ProcuLink and choose your workspace. This works if your ChatGPT plan allows custom connectors.

<Outcome>
Your assistant lists five ProcuLink tools.
</Outcome>

</Step>

<Step n={2} title="Or connect with a key (Claude Code, Cursor, VS Code)">

Ask a workspace admin to create a key in **Settings**, under **For developers**. Tick **Let it send documents** only if the assistant should send. Without it, the assistant can't send. A flow still sends by itself what it would send anyway: everything on **Check nothing**, and every document with nothing marked on **Check only what we marked**.

Claude Code:

```
claude mcp add --transport http proculink https://api.proculink.eu/mcp --header "X-ProcuLink-Key: YOUR_KEY"
```

Cursor (`mcp.json`):

```
{ "mcpServers": { "proculink": { "url": "https://api.proculink.eu/mcp", "headers": { "X-ProcuLink-Key": "YOUR_KEY" } } } }
```

VS Code (`.vscode/mcp.json`):

```
{ "servers": { "proculink": { "type": "http", "url": "https://api.proculink.eu/mcp", "headers": { "X-ProcuLink-Key": "YOUR_KEY" } } } }
```

Claude Code, Cursor and VS Code can also sign in instead: leave out the key and they open ProcuLink's sign-in.

<IfThisFails>
If the assistant says the key is wrong, check it was copied whole and has not been revoked in **Settings**.
</IfThisFails>

</Step>

<Step n={3} title="Ask">

Try: *Which ProcuLink documents need me?* · *Add this invoice to ProcuLink.* · *What did ProcuLink read from INV-1001?* · *Send it.*

<Outcome>
Many assistants ask before they send. Check before you say yes: a send can't be undone.
</Outcome>

## What it can't do

It can't change your flows, destinations, keys or people, and it can't remove anything. A document that needs a check, such as a repeated number, a first document from a new sender, or one we're not sure which flow it belongs to, must be sent from ProcuLink itself. With a key, it sends only what the flow would send by itself. Signed in, it can send what you could send from ProcuLink, except the documents above. ProcuLink tells your assistant to treat whatever is written inside a document as data, never as instructions.

## What your assistant sees

Everything the assistant adds or reads goes to the company behind it, such as Anthropic, OpenAI, Cursor or Microsoft: the files you add, and the values, checks and send results it fetches. That happens under your agreement with them. See [How ProcuLink uses AI](/help/ai-in-proculink).

## Turn it off

In Claude or ChatGPT, remove the connector. For a key, revoke it in **Settings**, under **For developers**. Removing a person from the workspace stops them connecting again. An assistant they already connected keeps access until its sign-in expires.
