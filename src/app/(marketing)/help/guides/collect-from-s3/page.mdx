export const metadata = guideMetadata({
  slug: "collect-from-s3",
  title: "Collect documents from an S3 bucket — ProcuLink guide",
  description: "Let ProcuLink collect new files from an S3 bucket.",
});

import { Step, Prereqs, IfThisFails, Outcome } from "@/components/help/guide";

<Prereqs>
- A flow, and a workspace admin account.
- An S3 bucket, or a bucket in a service that works like S3, such as R2 or MinIO.
- An access key for it: an access key ID and a secret access key. Read-only access is enough. We only list the objects and download them.
- For a service that is not Amazon S3, its web address. It must be reachable from the internet.
</Prereqs>

<Step n={1} title="Add a pickup">

Open the flow, go to the **Intake** tab, and find the **Pickups** card. Select **Add a pickup**. In the **Type** list, choose **S3 bucket**.

<Outcome>
The form shows the bucket fields.
</Outcome>

</Step>

<Step n={2} title="Fill in the bucket">

- **Bucket** is the bucket name.
- **Prefix** is optional. Type it to look only at objects whose names start with it, for example `invoices/`. Leave it empty to look at the whole bucket.
- **Region** starts as `us-east-1`. Use the region of your bucket.
- **Custom S3 address (for R2 or MinIO)** is only for services that are not Amazon S3. Leave it empty for Amazon S3.
- **Access key ID** and **Secret access key** are the key you made. The secret is stored encrypted.

Select **Save**.

<Outcome>
The pickup is saved. The **Test connection** button now works.
</Outcome>

<IfThisFails>
If the form refuses to save, the message says what is missing. A bucket and an access key ID are required. If you change the bucket, the region, the custom address or the access key ID later, enter the secret again.
</IfThisFails>

</Step>

<Step n={3} title="Test the connection">

Select **Test connection**. It lists the objects and counts the readable files that are waiting, but takes none.

<Outcome>
A message says "Connected." and how many files are waiting.
</Outcome>

<IfThisFails>
The message names the bucket and the reason it gave. Read it for the cause, such as a wrong key, a wrong region or a key without permission to list the bucket.
</IfThisFails>

</Step>

<Step n={4} title="Let it run">

Leave **On** ticked. Every five minutes we list the bucket and take each object we have not seen before.

- An object is taken once. If you replace it with a new version, it is taken again.
- Objects whose names end with a slash, which are folders in the console, are ignored. So are objects of a type we do not read.
- We take up to 50 files at a time, and the rest on the next check.
- An object over 10 MB is skipped, and the pickup's last message says so.
- Objects stay in the bucket. We do not move, rename or delete them.

<Outcome>
New documents appear on the flow's **Documents** tab. The pickup shows when it last ran and what it found, such as "Picked up 3 new file(s)."
</Outcome>

</Step>

## Good to know

Use a prefix when only part of a bucket is meant for ProcuLink. We look at everything under it.

To stop collecting, untick **On**, or select **Remove**.
