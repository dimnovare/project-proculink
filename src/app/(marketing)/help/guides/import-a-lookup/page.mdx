import { guideMetadata } from "@/lib/seo";

export const metadata = guideMetadata({
  slug: "import-a-lookup",
  title: "Import a lookup from a CSV or Excel file — ProcuLink guide",
  description: "Import a CSV or Excel file so a value on a document is replaced by the one your system uses.",
});

import { Step, Prereqs, IfThisFails, Outcome } from "@/components/help/guide";

<Prereqs>
- A CSV or Excel (.xlsx) file with headings in the first row and two columns. Column 1 holds the value as it appears on your documents (**From**). Column 2 holds the value your receiving system wants (**To**). Other columns are ignored.
- A flow with an output, to use the lookup in. See [Build an output](/help/guides/build-an-output).
</Prereqs>

<Step n={1} title="Import the table">

Open **Flows**, then **Lookups** under the list (or press Ctrl K and choose **Open Lookups**), and select **Import a table**. Choose your file.

<Outcome>
The rows are saved at once as a new lookup, named after the file, and it opens. A message says how many rows were saved. **Undo** in that message takes the import back.
</Outcome>

<IfThisFails>
A message starting "Couldn't import" says why: we read CSV files and Excel .xlsx files, a lookup holds at most 20,000 rows, and a value can be at most 200 characters.
</IfThisFails>

</Step>

<Step n={2} title="Check the rows">

Look through the rows and change anything needed. Changes save as you type. A row with the same **From** as one above it, or with a **To** and no **From**, says so and is not saved until you fix it.

<Outcome>
Beside the name it says "Saved, edits save as you type".
</Outcome>

<IfThisFails>
"Couldn't save" keeps what you typed. Select **Try again**.
</IfThisFails>

</Step>

<Step n={3} title="Use it in an output">

Open the output on the flow's **We send** step. Under **More options: when to send, separator, lookups**, choose the lookup beside the column you want to swap. Then choose what to do with a value that is not in it: **Keep the value** or **Leave it blank**. The change saves as a draft.

<Outcome>
The output swaps the value. **What the file looks like** shows the result. Values the lookup did not find are listed under the preview.
</Outcome>

</Step>

<Step n={4} title="Optional: let AI suggest matches">

If **Set up suggestions** appears on the lookup's page, select it and choose a CSV file, with headings in the first row, under **Import list (CSV)**. It saves by itself. Column 1 is the value, and the other columns become a note that helps pick it.

Then, when you preview an output and a value was not found, select **Suggest matches**. Nothing is added until you press **Accept**. See [Lookups](/help/lookups) for what is sent and how to accept, edit or reject.

<Outcome>
Accepted pairs join the lookup, and the preview updates.
</Outcome>

<IfThisFails>
No **Set up suggestions** means AI suggestions are not switched on for your workspace.
</IfThisFails>

</Step>

## Take the rows out again

Select **Export CSV** on the lookup's page.
