# How ProcuLink works

What happens to a document from the moment it arrives to the moment it is sent on.

## The path of a document

Every document takes the same path through a flow. A flow is one setup for one kind of document: how documents arrive, which values to read, what to produce and where it goes.

1. **It arrives.** You upload a file, forward it to the flow's email address, or let ProcuLink collect it from a mailbox, a server, an S3 bucket or the API. See [Ways to send documents in](/help/intake-channels).
2. **We read it.** We read the values and tables on the page. The first document needs no template. See [Files we read](/help/what-we-read).
3. **We check it.** A few checks flag a missing value, a value we could not read, or a document we have already seen. See [Checks](/help/checks).
4. **You review it, or we do not ask.** A new flow that an admin creates waits for you only on a document with a marked value (**Check only what we marked**). You can set a flow to **Check every document** or **Check nothing**. See [Flows](/help/flows).
5. **We make the file.** Each file in the flow is made from what we read, as CSV, JSON, XML, Excel, PDF, text or fixed-width. See [Files we make](/help/outputs).
6. **We send it.** Each file goes to its destination: an email address, a web address, an SFTP or FTPS server, an S3 bucket, Google Drive, Google Sheets, or a download. See [Destinations](/help/destinations).

On **Documents** you can follow each document's progress through five steps: In, Read, Check, Transform and Send.

## What you see on screen

On a wide screen, the original document stays on the left, and what we read sits beside it. A value we are not sure about is marked in amber and says how sure we are. If a value is wrong, change it, or point at the right place on the page and we remember it for next time. See [Senders](/help/senders).

The files we make and what has been sent are on the same screen, under **What we'll send**. No file is delivered until the document is sent, either by you or by the flow's check mode.

## The five things to know

- **Document:** one file that came in, with everything we read from it.
- **Flow:** the setup for one kind of document.
- **File we make:** a file we create from a document, in the format you choose.
- **Destination:** where each file we make goes.
- **Lookup:** an optional list that swaps one value for another, such as your code for a customer's code. See [Lookups](/help/lookups).
